# Hands-On Labs — CompTIA Linux+ (XK0-006)

30 hands-on labs, one folder per lab, sequenced on the five XK0-006 exam domains.
Every lab runs free in the browser on the [Killercoda Ubuntu Playground](https://killercoda.com/playgrounds/scenario/ubuntu) — no local install needed. Open a lab folder and follow its `README.md`.

| Domain | Weight | Labs |
|---|---|---|
| 1 · System Management | 23% | [Lab 1](lab-01-boot-fhs/) – [Lab 7](lab-07-virtualization/) |
| 2 · Services and User Management | 20% | [Lab 8](lab-08-files-directories/) – [Lab 13](lab-13-containers/) |
| 3 · Security | 18% | [Lab 14](lab-14-aaa-sudo-pam/) – [Lab 19](lab-19-compliance-audit/) |
| 4 · Automation, Orchestration, and Scripting | 17% | [Lab 20](lab-20-ansible/) – [Lab 24](lab-24-ai-best-practices/) |
| 5 · Troubleshooting | 22% | [Lab 25](lab-25-monitoring/) – [Lab 30](lab-30-capstone/) |

See [tools.md](tools.md) for the command/tool coverage map.
